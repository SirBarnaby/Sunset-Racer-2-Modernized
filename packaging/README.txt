Sunset Racer 2
==============

A standalone Windows rebuild of Inludo's Sunset Racer 2 Story Mode (build 376)
with widescreen 1080p, smooth motion and optional visual effects.

Play
----
Run SunsetRacer2.exe. Keep it in this folder with the other files: the game
needs all of them.

It runs on any 64-bit or 32-bit Windows 10 or 11 PC with DirectX 9. Nothing
else needs to be installed.

Settings
--------
Options > Display settings: full screen or window, window size, menu and HUD
size, anti-aliasing and the frame rate limit. Alt+Enter switches between full
screen and a window.

Options > Visual effects: the renderer, effects and 3D audio. A new install
starts with DirectX 9 and every effect off, which looks and sounds exactly like
the original game.

Renderer: DirectX 9 works everywhere. Vulkan is often faster on PCs with a
separate graphics card. If Vulkan cannot run on this PC (no Vulkan driver, or
a graphics card that is too old for it), the game uses DirectX 9 instead.

More: https://github.com/SirBarnaby/Sunset-Racer-2-Modernized
